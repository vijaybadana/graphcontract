# GraphContract visual system

This pack translates the ten-repository LangGraph evidence corpus into a coherent visual language for GraphContract. It is a design reference, not a collection of bitmap assets to embed in production. Implement each concept with React Flow, native HTML/CSS/SVG, and the repository's installed Phosphor icon library.
